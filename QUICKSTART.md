# Aura Pro: run it
1. Install Node.js 20+ (nodejs.org). Keep the folder outside OneDrive, e.g. C:\dev\aura-pro.
2. Double-click **start.bat**. First run opens `server\.env` in Notepad: paste your keys (see KEYS-GUIDE.md), save, close, press any key.
3. Open http://localhost:5173

Minimum to test: MONGODB_URI + GEMINI_API_KEY.
Add Facebook keys for Facebook posting; add Facebook + Cloudinary keys for Instagram posting too. No ngrok needed.
